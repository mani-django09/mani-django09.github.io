How to reduce the file size of an image (JPG, PNG, WebP)

By Manikant Yadav, maker of SmallPDF.us · Updated 2026-10-13

Big images slow down websites and fill up inboxes. Making them smaller is simple when you follow three steps in the right order: choose the format, resize, then compress.

1. Choose the right format

FormatBest forNotes
JPGPhotosSmall files, no transparency
PNGLogos, screenshots, graphics with textSharp edges and transparency, larger files
WebPWebsitesUsually smaller than JPG and PNG, supported by all modern browsers

A screenshot saved as JPG looks smudgy around the text, and a photo saved as PNG is huge. Matching the format to the content is the biggest single win.

2. Resize first

A 4000-pixel-wide photo shown at 800 pixels on a web page is wasted bytes. Resize to the largest size you will really display, then compress. This alone can cut the file to a fraction of its size.

3. Compress

  1. Open Compress Image and upload your files.
  2. Use a quality around 70-85 for photos. Below about 60 you start to see blocky artifacts.
  3. Compare the result with the original at 100% zoom, not as a thumbnail.

Converting between formats

  • PNG to WebP for web use.
  • WebP to PNG when software that does not support WebP complains.
  • HEIC to JPG for iPhone photos.
Privacy: photos can contain location data in their metadata. Compressing usually removes most of it, but check before posting sensitive pictures.
