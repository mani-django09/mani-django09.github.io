How to merge several PDF files into one

By Manikant Yadav, maker of SmallPDF.us · Updated 2026-10-13

Sending one PDF is far easier than sending five. Whether you are putting together an application, a report or a set of invoices, merging is quick once you know the few things that can go wrong.

Before you merge

  • Name the files in order. Prefix them with 01, 02, 03 so they are easy to arrange.
  • Unlock protected files. A PDF with an open password must be unlocked first. If you know the password, use Unlock PDF.
  • Fix sideways pages. Rotate them first with Rotate PDF, so the merged document does not have upside-down pages.

Steps

  1. Open Merge PDF.
  2. Add your files. You can add several at once.
  3. Drag them into the final order. The first file becomes the first pages of the result.
  4. Merge, download, and scroll through the result once to check the order.

Mixed page sizes

If you merge an A4 document with a US Letter one, pages keep their own size. That is normal and prints fine. If it bothers you, export the originals to the same paper size first.

Merged file too big?

Merging does not add size, it adds up the sizes. Run the result through Compress PDF when you need to stay under an upload limit.

Need only some pages?

Use Split PDF to pull out the pages you want, then merge those. This is the quickest way to build a short document from several long ones.

Privacy note: do not merge confidential documents on a computer or service you do not trust. Check the privacy policy of any online tool, including ours.
